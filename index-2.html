Ruang obrol ini butuh Firebase (gratis) biar pesannya nyambung real-time. Langkahnya:
  1. Buka console.firebase.google.com, bikin project baru (gratis, gak perlu kartu kredit)
  2. Build → Firestore Database → Create database → pilih mode test
  3. Build → Authentication → Get started → Sign-in method → aktifkan Anonymous
  4. Klik ikon gerigi Project settings → scroll bawah → Add app → Web (</>)
  5. Copy objek firebaseConfig, tempel di kode ini (cari komentar GANTI DI SINI)
